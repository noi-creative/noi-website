## Decisions

- **The text-bubble sticker is used once, not twice.** The new `sticker-text-bubble.svg` is a single multi-path sticker that already renders as two overlapping text-bubble shapes (blue back + yellow front). Using it twice (with different rotations) would be redundant. Using it once matches the available asset and the Figma's two-bubble composition.
- **The calendar sticker is used once, replacing the inline SVG.** The new `sticker-calendar.svg` is a single yellow calendar with a sticky note attached, matching the Figma exactly. The inline 160×160 SVG is deleted.
- **Both stickers render via `next/image`, not as inline SVG.** Consistent with the P05 pattern (the semi-circles were also `next/image`) and with AGENTS.md §12 ("Use `next/image` for every meaningful raster image unless technically incompatible"). SVG assets use `next/image` for `sizes` and lazy-loading.
- **The stickers carry `alt=""` and `aria-hidden="true"` on the parent.** They are decorative. The CTA's content is the heading, the lede, and the button. The stickers are visual atmosphere, not content.
- **The left grid becomes a single centered sticker.** The P05 layout used 2 overlapping semi-circles (one blue, one orange) at 90% / 50% widths with different rotations. The new text-bubble sticker is a single complex shape, so the wrapper becomes a single centered sticker. The wrapper keeps the `min-height: 14rem` so the layout doesn't collapse when the sticker is hidden < 768 px.
- **The sticker sizes use `clamp()` for fluid sizing.** The P05 semi-circles used `width: 90%` / `width: 50%` (relative to the grid cell). The new stickers are nearly square (208×205 and 209×196), so absolute `clamp()` values are the right tool: `clamp(140px, 14vw, 210px)` for the text-bubble (slightly larger because it replaces 2 overlapping shapes) and `clamp(120px, 12vw, 180px)` for the calendar (same range as the P05 inline SVG).
- **The rotations are preserved.** The text-bubble sticker rotates -8° (replacing the P05 blue -12° / orange +8° combination, which balanced the 2 shapes; the new sticker is a single shape, so a smaller rotation looks better). The calendar sticker rotates -6° (same as the P05 inline SVG).
- **No new dependencies.** The implementation uses `next/image`, the C06 primitives, and the existing data files. No package changes.
